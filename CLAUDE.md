# Golda iOS

Форк Android-приложения Golda (Kotlin, Compose). Идёт порт на нативный iOS: Swift, SwiftUI, iOS 26+, только iPhone. Работа — в ветке `ios-port`, код iOS — в `ios/`.

## Документы

- Любая задача начинается с `docs/ios/ROADMAP.md`: найди этап, его критерий готовности, по завершении поставь статус.
- Структура, данные, синхронизация, голос, соответствие Android → iOS: `docs/ios/ARCHITECTURE.md`.
- Экран, цвет, компонент, иконка, анимация: `docs/ios/DESIGN.md`.
- Перед изменением решённого и при новом решении: `docs/ios/DECISIONS.md` (новое решение запиши туда).
- Поведение приложения: `SPEC.md` (русский) описывает его целиком. iOS ведёт себя так же; отличия живут только в `DECISIONS.md`.

## Эталон

Kotlin-код в `app/` (кроме `ui/`) и его юнит-тесты — спецификация логики. Порт идёт тестами вперёд: переведи Kotlin-тест в Swift, получи красный, затем перенеси код до зелёного. Перевод теста меняет синтаксис и способ проверки текстов (домен отдаёт структуру, не строки); сами ожидания остаются. Расхождение с результатом Kotlin — баг порта, пока `DECISIONS.md` не говорит обратного.

Android-код остаётся нетронутым: правки приходят только из upstream (`shamil-aminov/golda`), так слияние идёт без конфликтов. Android удаляется одним коммитом на этапе 7.

## Правила

Продукт (из `CONTRIBUTING.md`, там они живут до этапа 7):
- Деньги — `Int64` в минорных единицах. Курсы — единственные числа с плавающей точкой, применяются один раз, на краю.
- Модель голоса только извлекает сказанное; суммы, курсы и оценки считает код.
- Записывается только руками или голосом.
- Весь учёт принадлежит профилю («Личный», «Семья»…): счета, операции, цели, вишлист, платежи, доход, день зарплаты. Профиль — единица шаринга; домен о профилях не знает.
- Золото — у одного главного действия экрана; выбранное — графит; красный — плохие новости.
- Каждая строка интерфейса есть на русском и английском, обе — в одном изменении.

Код:
- Swift 6, строгая конкурентность. Тесты — Swift Testing; сценарии интерфейса — XCUITest.
- `GoldaCore` импортирует только Foundation; UI, GRDB, CloudKit и AVFoundation живут снаружи.
- Округление денег идёт через `Money.roundHalfUp` (поведение Kotlin `roundToLong()`): `.rounded()` Swift на отрицательных .5 даёт другой результат.
- Идентификаторы записей — UUID; Int-id есть только при импорте Android-бэкапа.
- Синхронизация и голосовой провайдер стоят за протоколами; тесты работают с заглушками, без сети и iCloud.
- Ключи API лежат в Keychain (`ThisDeviceOnly`); в бэкапы и логи они не попадают.
- `.xcodeproj` генерирует XcodeGen из `ios/project.yml` и держит в `.gitignore`; правки — в `project.yml`.
- Комментарии по-английски, объясняют «почему»; имена говорят, что это. Образец стиля — соседний код.

Процесс:
- Коммит — только по просьбе владельца; сообщение — короткая английская строка в повелительном наклонении.
- Задача закрыта, когда обновлены статус в `ROADMAP.md` и, для нового решения, `DECISIONS.md`.
- Этапы с пометкой 🔑 требуют подписи командой Apple (iCloud, устройство, TestFlight); остальные идут на симуляторе без неё.
- Лицензия MIT оригинала: `LICENSE` и `NOTICE` с авторством Shamil Aminov остаются в репозитории и в экране «О приложении».
