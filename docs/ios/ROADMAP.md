| Риск | Что делаем |

| Связка `CKSyncEngine` + shared БД + зона на профиль ведёт себя не так, как в документации | Спайк 5a до любой разработки синхронизации; транспорт за протоколом. |

## Синхронизация с upstream

1. Один раз: `git remote add upstream https://github.com/shamil-aminov/golda.git`.
2. `git fetch upstream && git merge upstream/main` — конфликтов быть не должно, пока `app/` нетронут.
3. Смотри `git diff <база>..upstream/main -- SPEC.md app/src/main/java/sh/aminov/golda/domain app/src/test`. Каждое изменение — отдельная задача: тест, затем код в `GoldaCore`, затем UI.
4. Обнови «Базовую версию Android» в начале файла.
